# КАРТОЧКА ПРОЕКТА МИГРАЦИИ

## Общая информация
- **Название проекта:** Ding
- **Источник:** Пет-проект
- **URL репозитория (исходный):** https://github.com/Ella-Ksenofontova/Ding/ 
- **Язык программирования:** Python + TypeScript
- **Фреймворк:** FastAPI + React + Bootstrap
- **Лицензия:** в оригинальном проекте не указана, но я разрешаю использовать код проекта и использованные в нём медиа (последние - с указанием авторства)
- **Размер кодовой базы:** ~2000 строк кода, ~200 файлов

## Архитектура
- **Тип приложения:** модульное
- **Количество компонентов:** 3
- **Используемая СУБД:** PostgreSQL
- **Контейнеризация:** Docker

## Функциональное назначение
Учебный проект представляет собой имитацию соцсети для видео на моём канале. Имеется клиент ("соцсеть"), сервер, который взаимодействует с базой данных, а также панель управления, позволяющая изменять информацию об объектах, присутствующих в системе.

## Текущая инфраструктура
- **Хостинг кода:** GitHub
- **CI/CD:** отсутствует
- **Развёртывание:** контейнерное

## АНАЛИЗ ЗАВИСИМОСТЕЙ

### Критические уязвимости
`npm audit` **не нашёл** критических уязвимостей, однако были найдены серьёзные (high severity).
`pip-audit` нашёл 26 уязвимостей, но неясно, какие из них критические, а какие - нет. Большая часть приходится на `pip` и `tornado` - Web-фреймворк на Python.
### Зависимости, требующие замены
На мой взгляд, никакие зависимости не требуют замены, так как критических уязвимостей, по-видимому, нет. К тому же проект предназначен для личного использования.
### Итоговая оценка
- **Общее количество зависимостей:** 461
- **Критических уязвимостей:** 0
- **Требуют замены:** 0
- **Общая оценка рисков миграции:** низкая
