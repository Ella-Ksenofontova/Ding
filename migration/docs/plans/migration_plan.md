# ПЛАН МИГРАЦИИ ПРОЕКТА Ding

## 1. Паспорт проекта

### 1.1. Исходное состояние
- **Название:** Ding
- **Язык / Фреймворк:** Python + TypeScript
- **Исходная СУБД:** PostgreSQL
- **Исходный хостинг кода:** GitHub
- **Исходная инфраструктура:** GitHub + Docker

### 1.2. Целевое состояние
- **ОС:** Astra Linux
- **Хостинг кода:** Gitverse
- **СУБД:** PostgreSQL/Tantor
- **Мониторинг:** Zabbix
- **Аналитика:** ClickHouse
- **CI/CD:** Gitverse CI

## 2. Анализ рисков

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Несовместимость зависимостей | Высокая |  Увеличивается время на разработку, усложняется обновление системы |Отказ от избыточных зависимостей |
| Потеря данных при миграции |Средняя | Приходится заново заполнять все данные | Регулярный бэкап |
| Снижение производительности |Высокая | Конечному пользователю становится труднее работать с системой| Зараннее продуманные хранение и обработка данных |
| Отсутствие поддержки | Средняя | Увеличивается время на разработку, становится труднее поддерживать код | Связь непосредственно с разработчиком либо замена утилиты на имеющую поддержку |
