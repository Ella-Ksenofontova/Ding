Панель управления "соцсетью" для кукол Ding 
===
Функционал
----
Это приложение даёт возможность просматривать, удалять, редактировать и создавать:
* Пользователей
* Посты
* Группы 
* Комментарии 
* Уведомления
* Сообщения
* Чаты

Стек технологий
----
* React 
* React Router
* Vite
* React Bootstrap + React Bootstrap Icons
* TypeScript
